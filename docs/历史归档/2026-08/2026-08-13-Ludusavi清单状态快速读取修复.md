# Ludusavi 清单状态快速读取修复实施计划

> **供智能体执行者使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施本计划。各步骤使用复选框（`- [ ]`）跟踪进度。

**目标：** 让 `ludusavi_status` 在已有完整文件组时只读取元数据并校验清单摘要，不再为展示状态完整解析约 17.5 MB 的 YAML，同时保留首次安装、实际匹配和更新下载时的完整内容校验。

**架构：** `LudusaviProvider.metadata()` 先走快速路径：读取活动元数据并以流式 SHA-256 校验活动清单；只有文件组缺失、元数据无效或摘要不匹配时，才调用现有 `ensure_initial_snapshot()` 做完整恢复。`load()`、初始快照安装、备份恢复和下载替换仍使用 `_validate_pair()` 完整解析 YAML，因此快速状态查询不会削弱进入匹配流程的数据校验。

**技术栈：** Python 3.12、PyYAML、pytest、ruff、mypy。

## 全局约束

- 状态查询不得联网，也不得完整解析大型 YAML。
- 状态查询必须校验活动 `manifest.yaml` 与 `manifest-meta.json` 是完整且 SHA-256 一致的文件组。
- 快速校验失败时必须沿用现有恢复链：最近有效备份，再回退内置清单。
- `load()` 和下载更新仍必须完整解析 YAML；无效内容不能进入存档匹配。
- 不改变 pywebview 桥接契约或前端显示结构。
- 不顺带实现“查找存档改为手动触发”；该行为调整另立任务。
- 按 TDD 实施，先确认回归测试会失败，再修改生产代码。

- [ ] **步骤 3：实现最小快速路径**

将 `metadata()` 改为先校验活动文件组；校验失败才执行现有完整恢复：

```python
def metadata(self) -> SnapshotMetadata:
    with self._lock:
        try:
            return self._active_metadata_if_integrity_valid()
        except (OSError, SnapshotUpdateError):
            self.ensure_initial_snapshot()
            return self._active_metadata_if_integrity_valid()

def _active_metadata_if_integrity_valid(self) -> SnapshotMetadata:
    if not self.active_manifest.is_file() or not self.active_metadata.is_file():
        raise SnapshotUpdateError("Ludusavi 清单文件组不完整。")
    metadata = _read_metadata(self.active_metadata)
    if _sha256_file(self.active_manifest) != metadata.sha256:
        raise SnapshotUpdateError("Ludusavi 清单的 SHA-256 与元数据不一致。")
    return metadata
```

不得修改 `ensure_initial_snapshot()`、`load()`、`_validate_pair()` 或 `_validate_manifest_bytes()` 的完整解析行为。

def test_metadata_recovers_hash_mismatched_active_pair(
    provider: tuple[LudusaviProvider, FakeHttp],
) -> None:

    backup = service._backup_active_pair()

## 完成标准

- `ludusavi_status` 不再因完整解析 17.5 MB YAML 而长时间显示“正在读取清单状态”。
- 快速状态路径仍验证元数据格式、文件存在性和 SHA-256 一致性。
- 摘要不一致或文件组缺失时，仍执行完整的备份/内置清单恢复。
- 实际清单加载和下载替换继续执行完整 YAML 解析。
- Python、前端、静态检查、类型检查和构建门禁全部通过。
