- [ ] **Step 1：删除 GitHub Release，脚本不得打印令牌**

```powershell
$credentialInput = "protocol=https`nhost=github.com`n`n"
$credentialLines = $credentialInput | git credential fill
$credential = @{}
foreach ($line in $credentialLines) {
  $parts = $line -split '=', 2
  if ($parts.Length -eq 2) { $credential[$parts[0]] = $parts[1] }
}
if (-not $credential.password) { throw 'Git 凭据管理器没有返回 GitHub 令牌' }
$releaseId = ((Get-Content -LiteralPath build/history-rewrite-backup/state.txt) | Where-Object { $_ -like 'releaseId=*' }).Split('=')[1]
$headers = @{
  Authorization = "Bearer $($credential.password)"
  Accept = 'application/vnd.github+json'
  'X-GitHub-Api-Version' = '2022-11-28'
}
Invoke-RestMethod -Method Delete -Headers $headers -Uri "https://api.github.com/repos/zyj13547810610/GameSave-Scout/releases/$releaseId"
Remove-Variable credentialLines, credential, headers
```

预期：DELETE 返回成功；日志不包含 Authorization 值。
