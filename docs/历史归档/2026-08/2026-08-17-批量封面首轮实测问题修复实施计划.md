- [x] **步骤 4：实现最小游戏级适配器**

在 `wizard_service.py` 中导入 `CoverProgressDetail`，并加入：

```python
@dataclass(frozen=True)
class _VndbBatchProgress:
    parent: CoverProgress
    completed_games: int
    total_games: int
    current_index: int
    game_id: str
    game_title: str

    def report(self, completed, total, message, *, details=None) -> None:
        del completed, total
        merged: dict[str, CoverProgressDetail] = dict(details or {})
        merged["gameId"] = self.game_id
        merged["currentIndex"] = self.current_index
        self.parent.report(
            self.completed_games,
            self.total_games,
            f"正在搜索 {self.current_index}/{self.total_games}：{self.game_title} · {message}",
            details=merged,
        )

    def raise_if_cancelled(self) -> None:
        self.parent.raise_if_cancelled()
```

`collect_vndb()` 在每个游戏开始前先报告 `index - 1 / total`，把适配器传入 `search()`；成功或 `VndbError` 隔离后都报告 `index / total`。失败消息明确“搜索失败，继续下一个”，保证任务正常完成时最终进度为总数。

循环的进度调用保持以下结构：

```python
total_games = len(game_ids)
for index, game_id in enumerate(game_ids, start=1):
    game = self._require_game(game_id)
    batch_progress = _VndbBatchProgress(
        context, index - 1, total_games, index, game.id, game.title
    )
    batch_progress.report(0, None, "正在查询 VNDB")
    try:
        candidates = self._vndb.search(
            game.title, limit, session.root, game_id, batch_progress
        )
    except VndbError as error:
        with self._lock:
            self._mark_failed_if_active(session_id, game_id, str(error))
        context.report(
            index,
            total_games,
            f"{game.title} 的 VNDB 搜索失败，继续下一个",
            details={"gameId": game_id},
        )
        continue
    # 保留现有候选合并
    context.report(
        index,
        total_games,
        f"已完成 {game.title} 的 VNDB 搜索",
        details={"gameId": game_id},
    )
```

- [x] **步骤 3：实现统一进度区域**

在工具栏中根据任务快照计算展示完成数：运行中钳制到 `0..total`；`status === 'completed'` 且总数大于零时显示总数。模板使用：

```typescript
const props = defineProps<{
  game: Game | null
  settings: CoverWizardSettings
  sourceActive: boolean
  task: TaskSnapshot | null
}>()

const displayedCompleted = computed(() => {
  const task = props.task
  const total = task?.progress.total
  if (!task || total === null) return 0
  if (task.status === 'completed') return total
  return Math.min(Math.max(task.progress.completed, 0), total)
})

const progressMax = computed(() => Math.max(props.task?.progress.total ?? 1, 1))
```

```vue
<div
  v-if="task"
  data-test="cover-task-progress"
  class="cover-task-panel"
  :class="`status-${task.status}`"
>
  <p class="cover-task-progress" role="status" aria-live="polite">
    <span>{{ task.message || '正在收集候选…' }}</span>
    <strong v-if="task.progress.total !== null">
      {{ displayedCompleted }}/{{ task.progress.total }}
    </strong>
  </p>
  <progress
    aria-label="候选收集进度"
    :max="progressMax"
    :value="task.progress.total === null ? undefined : displayedCompleted"
  />
</div>
```

原生 `<progress>` 没有 `value` 时自动成为动态进度；CSS 提供整行深色背景、明显紫色进度和完成时绿色强调。该组件自然覆盖 VNDB、浅层扫描和目录导入，因为三者都复用 `taskSnapshot`。
