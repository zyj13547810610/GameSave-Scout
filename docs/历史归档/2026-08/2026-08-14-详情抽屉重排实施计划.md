# GameShelf 详情抽屉重排实施计划

> 实施状态：已完成。详情抽屉顶部、游戏设置、存档位置、引擎分区、危险操作和自适应布局均已重排并完成质量门禁。

> **执行要求：** 使用 `superpowers:executing-plans` 在当前会话逐项执行；用户已明确不使用子代理，并要求直接在本地 `main` 修改。

**目标：** 把右侧详情抽屉改为自适应宽度、居中大原图封面和清晰的六段式布局，同时减少常用操作所需点击与低频内容占用的高度。

**架构：** 保留现有模态抽屉、滚动锁定、焦点陷阱和业务桥接接口。让游戏设置、存档位置分别拥有自己的原生 `<details>` 分区，新建 `EngineSection.vue` 统一自动识别与手动设置；`GameDetailDrawer.vue` 只负责顶部概览、分区编排、快捷启动和记录危险操作。

**技术栈：** Vue 3、TypeScript、Vue Test Utils、Vitest、CSS、pywebview 桥接接口。

## 全局约束

- 详情宽度使用 `width: clamp(32rem, 40vw, 48rem)` 和 `max-width: 92vw`。
- 详情原图使用 `object-fit: contain`；主页 2:3 裁剪缩略图逻辑不变。
- 内容顺序固定为：概览、封面操作、游戏设置、存档位置、游戏引擎、游戏记录。
- 游戏设置和存档位置默认展开；游戏引擎和游戏记录默认折叠。
- 关闭详情后不记忆折叠状态；重新打开恢复默认值。
- 安装路径、存档路径均可点击打开；主程序路径和重新选择入口必须保留。
- 不新增后端 API、自动扫描、网络请求或游戏目录读取。
- 保留单一关闭按钮、遮罩关闭、`Esc`、焦点陷阱和独立滚动。

```vue
<script setup lang="ts">
import { computed } from 'vue'
import type { Game, GameShelfBridge } from '../../api/contracts'
import EngineDetails from './EngineDetails.vue'
import EnginePicker from './EnginePicker.vue'

const props = defineProps<{ game: Game; bridge: GameShelfBridge }>()
defineEmits<{ updated: [game: Game] }>()

const warning = computed(() => !props.game.detectedEngine || props.game.detectedEngine.ambiguous)
const modeLabel = computed(() => props.game.engineIsManual ? '手动设置' : '自动识别')
const confidenceLabel = computed(() => {
  if (props.game.engineIsManual || !props.game.detectedEngine?.confidence) return ''
  return `${props.game.detectedEngine.confidence}可信度`
})
</script>

<template>
  <details data-test="engine-section" class="detail-section engine-section">
    <summary :class="['detail-section-summary', { warning }]">
      <span>游戏引擎</span>
      <small>{{ [game.engineLabel, modeLabel, confidenceLabel].filter(Boolean).join(' · ') }}</small>
    </summary>
    <div class="detail-section-body">
      <EngineDetails
        :show-heading="false"
        :adopted="{ id: game.engineId, label: game.engineLabel, variant: game.engineVariant, manual: game.engineIsManual }"
        :detected="game.detectedEngine"
      />
      <EnginePicker :game="game" :bridge="bridge" @updated="$emit('updated', $event)" />
    </div>
  </details>
</template>
```

import EngineSection from '../engines/EngineSection.vue'

const quickBusy = ref(false)
const quickMessage = ref('')

async function launchGame() {
  quickBusy.value = true
  quickMessage.value = ''
  const result = await props.bridge.launch_game({ gameId: props.game.id })
  quickBusy.value = false
  quickMessage.value = result.ok ? `游戏已启动（PID ${result.data.pid}）` : result.error.message
}

async function openInstallDirectory() {
  quickMessage.value = ''
  const result = await props.bridge.open_install_directory({ gameId: props.game.id })
  if (!result.ok) quickMessage.value = result.error.message
}
