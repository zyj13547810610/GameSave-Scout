# 顶部全局导航与工具工作区实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把游戏库、批量存档、批量封面和规则管理统一为窗口顶部四个直接一级入口，同时保留游戏库独立目录栏、工具页全宽布局、封面会话安全退出和主页上下文恢复。

**Architecture:** `App.vue` 继续承担单窗口工作区编排，不引入 Vue Router。现有左侧壳层改为“顶部全局栏 + 剩余工作区”；游戏库视图用 `v-show` 保留目录和游戏滚动状态，三个工具工作区按当前入口挂载。批量封面组件从模态对话语义改为普通一级工作区，并通过暴露的异步离开守卫让父级导航先取消任务、关闭会话和清理临时候选，再切换目标工作区。

**Tech Stack:** Vue 3、TypeScript、Pinia、Vitest、Vue Test Utils、CSS Grid/Flex、pywebview/WebView2。

**Spec:** `docs/superpowers/plans/2026-08-12-GameSave-Scout-03-封面与游戏库界面.md`；总体边界见 `docs/superpowers/specs/2026-08-12-GameSave-Scout-总体设计.md`。

## Global Constraints

- 直接在当前本地 `main` 分支实施，不创建开发分支或额外 worktree。
- 不使用子代理；按 `superpowers:executing-plans` 在当前会话逐项执行。
- 不引入 Vue Router、新 Windows 窗口、新数据库表、schema 迁移或新依赖。
- 顶部入口固定顺序为“游戏库、批量存档、批量封面、规则管理”，五档缩放和 `960 × 640` 下不得折叠进菜单。
- 游戏目录只在游戏库可见；工具工作区使用顶栏以下全部宽度。
- 离开规则管理必须保留未保存草稿确认；离开批量封面必须完成会话关闭语义后才切换。
- 批量封面联网、文件读取、采用和临时文件边界保持不变，本轮只调整工作区装配与导航生命周期。
- 所有仓库内设计、实施和验收记录使用中文；完成实现后同步固定文档、路线图和 README。

- [ ] **Step 3: 将应用壳层改成顶部全局栏与剩余工作区**

在 `frontend/src/App.vue` 中完成以下最小实现：

```ts
type AppView = 'library' | 'batch_saves' | 'covers' | 'rules'
type CoverWorkspaceHandle = { requestClose: () => Promise<boolean> }

const activeView = ref<AppView>('library')
const coverWorkspace = ref<CoverWorkspaceHandle | null>(null)

async function changeView(view: AppView): Promise<boolean> {
  if (activeView.value === view) return true
  if (
    activeView.value === 'rules'
    && ruleManagementStore.dirty
    && !window.confirm('当前规则草稿尚未保存，确认放弃并离开规则管理吗？')
  ) return false
  if (activeView.value === 'covers') {
    const closed = await coverWorkspace.value?.requestClose()
    if (closed === false) return false
    const latest = await bridge.bootstrap()
    if (latest.ok) coverWizardSettings.value = latest.data.coverWizardSettings
  }
  if (activeView.value === 'rules') ruleManagementStore.discardDraft()
  selectedGameId.value = null
  showGroupManager.value = false
  showBatchGroup.value = false
  showAddRoot.value = false
  editingRoot.value = null
  exitBatchMode()
  activeView.value = view
  return true
}
```

模板把品牌、四个导航按钮、五档缩放和只在游戏库显示的“添加游戏目录”放入 `.app-global-header`。游戏库布局内部包含 `ScanRootList` 与 `.library-content`，用 `v-show="activeView === 'library'"` 保留同一 DOM；批量存档、批量封面、规则管理分别按 `activeView` 挂载，三个工具页不渲染目录栏。

- [ ] **Step 4: 把批量封面改为可受父级导航控制的普通工作区**

在 `CoverWizardWorkspace.vue` 中：

```ts
let openingPromise: Promise<void> | null = null

onMounted(() => {
  openingPromise = (async () => {
    await store.open(props.bridge)
    opening.value = false
  })()
})

async function requestClose(): Promise<boolean> {
  await openingPromise
  if (!store.session) {
    store.clearPolling()
    return true
  }
  if (store.activeTaskId && !window.confirm('退出将取消正在进行的搜索，并清理未采用候选。是否继续？')) {
    return false
  }
  return store.requestClose(props.bridge)
}

defineExpose({ requestClose })
```
