# GameShelf 主页与批量封面视口壳层实施计划

> 实施状态：待开始。设计已经写入固定模块 03 文档；本计划只覆盖前端视口壳层、内部滚动、候选设置浮层和深色滚动条，不修改后端与数据模型。

> **供智能代理执行：** 必须使用 `superpowers:executing-plans` 按任务顺序实施；本项目明确不使用子代理。步骤使用复选框跟踪。

**目标：** 把主页和批量封面工作台改为无页面级纵向滚动的 `100dvh` 桌面壳层，使目录/游戏内容及队列/候选画廊分别独立滚动，候选设置以浮层展开，并让所有自有滚动区域使用一致的深色滚动条。

**架构：** 保留现有 Vue 组件、Pinia 会话和 Python 桥接边界，只重新划分前端 DOM 与 CSS 高度链。应用外层固定在视口内，Grid/Flex 剩余行和所有可滚动子项使用 `minmax(0, 1fr)` 或等效的 `min-height: 0`；每个业务组件只拥有自己的明确滚动容器。候选设置组件内部管理浮层开关、外部点击和焦点恢复，不新增全局状态。

**技术栈：** Vue 3、TypeScript 5.9、Pinia 3、CSS Grid/Flex、WebView2、Vitest 3、Vue Test Utils、jsdom 26、Vite 7。

## 全局约束

- 直接在当前本地 `main` 工作，不创建分支或 worktree，不使用子代理。
- 每个任务修改并验证成功后直接提交 Git；未经用户明确要求不得执行 `git push`。
- 仓库设计和开发文档使用中文；固定事实来源为模块 03 设计文档和开发路线图，本计划归档在 `docs/历史归档/2026-08`。
- 不新增 Python、前端运行时或开发依赖；不修改 Python、SQLite schema、封面候选服务、桥接协议或 `data/config.json`。
- pywebview 最小窗口保持 `960 × 640`，默认窗口保持 `1180 × 760`。
- 界面缩放完整覆盖 80%、90%、100%、110%、120% 五档，不能只验证三个代表档位。
- 主页外层和批量封面工作台外层都不得承担纵向滚动；所有滚动必须落在文档指定的内部区域。
- 主页常规状态只有目录列表和游戏内容两个业务滚动区；批量封面常规布局只有游戏队列和候选画廊两个业务滚动区，窄布局只有候选画廊一个主要滚动区。
- 内部滚动统一使用 `overscroll-behavior-y: contain` 和稳定滚动条槽位；内容不足时不强制显示滚动条。
- 深色滚动条使用纯 CSS，不使用 JavaScript 自绘滚动组件；标准属性不受支持时允许退回系统样式。
- 深色滚动条目标颜色为轨道透明或 `#17151e`、默认滑块 `#4d4856`、悬停 `#686173`、拖动 `#81778f`，目标宽度约 `10px`，WebView2 下隐藏白色箭头按钮。
- 保留现有搜索、筛选、批量管理、详情抽屉、拖放、来源任务、采用、跳过、取消、错误恢复和焦点约束语义。
- 自动测试不得访问真实网络；本任务不需要再次调用真实 VNDB。

```ts
const root = ref<HTMLElement | null>(null)
const trigger = ref<HTMLButtonElement | null>(null)
const open = ref(false)

async function closeAndRestoreFocus() {
  open.value = false
  await nextTick()
  trigger.value?.focus()
}

function onDocumentPointerDown(event: PointerEvent) {
  if (!open.value || root.value?.contains(event.target as Node)) return
  void closeAndRestoreFocus()
}

onMounted(() => document.addEventListener('pointerdown', onDocumentPointerDown))
onBeforeUnmount(() => document.removeEventListener('pointerdown', onDocumentPointerDown))
```
