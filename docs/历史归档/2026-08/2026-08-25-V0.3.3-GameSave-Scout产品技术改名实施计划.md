# V0.3.3 GameSave Scout 产品技术改名实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. 本项目明确要求不使用子代理，所有实施、审查和验证都在当前会话内完成。

**目标：** 把 V0.3.2 仍使用的 `GameShelf` / `gameshelf` 技术标识完整收口为 V0.3.3 的 GameSave Scout 单一身份，生成并验证两套新名称便携包，同时保持程序旁 `data` 与 SQLite schema 4 不变。

**架构：** 采用分层收口：先移动 Python 包并更新后端运行时身份，再更新前端桥接与品牌，然后更新 PyInstaller 和双版本发布链，最后执行全仓旧入口审计、历史代码原型同步、完整构建和仓库/目录收口。每层先修改会失败的验收，再做最小机械改名并运行该层门禁；不引入旧包、旧命令或旧环境变量兼容层。

**技术栈：** Python 3.12、setuptools、pytest、Ruff、mypy、Vue 3、TypeScript、Pinia、Vitest、Vite、pywebview、PyInstaller 6、PowerShell、Git。

**规格：**
