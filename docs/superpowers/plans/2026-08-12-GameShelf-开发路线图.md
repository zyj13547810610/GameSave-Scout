# GameShelf 开发路线图

> 文档性质：项目唯一有效的版本路线图与开发状态；最后更新：2026-08-13。

## 1. 产品方向

GameShelf 是面向 Windows 10/11 x64 的本地优先、便携式个人游戏库与存档位置管理器，主要服务单机游戏、Galgame、DLsite 作品和 RPG Maker 等非平台统一管理的游戏。

项目不依赖 Steam 等平台导入。用户配置一个或多个游戏根目录，GameShelf 扫描目录建立游戏库，并允许用户维护封面、启动配置、引擎信息和存档位置。

## 2. 版本原则

- 先交付稳定的游戏库，再扩展复杂存档发现。
- 游戏发现不依赖引擎识别。
- 自动结果必须可解释，并允许用户纠正。
- 扫描与规则读取默认只读，不执行未知程序。
- 不在用户不知情时联网或扫描全盘。
- 所有自动发现都经过用户审核后才成为正式记录。
- 配置、封面、数据库和可更新规则都位于程序旁 `data`。

## 5. V0.1 首发范围

### 已实现

- 多个用户指定游戏根目录。
- 直接子目录和 1～8 层递归扫描。
- 根目录排除规则和启用开关。
- 启动快速核验与手动完整扫描。
- 安装状态、移动建议和根目录重映射。
- 主 EXE 推荐、手动选择、参数、工作目录和环境变量。
- 一张封面，支持本地选择和粘贴截图。
- 搜索、状态/引擎筛选和右侧详情抽屉。
- 80%～120% 界面缩放。
- 第一批 Galgame、RPG Maker、Unity、Ren'Py 等引擎识别。
- 引擎证据、歧义处理和手动覆盖。
- 每个游戏多个手动存档位置。
- 按需使用自定义清单、Ludusavi 和引擎提示查找存档。
- Ludusavi 本地种子、显式更新、完整性校验、备份恢复和失败降级。

### 首发前仍需完成

按当前优先级：

1. **游戏记录生命周期**
   - 为已安装项目增加“从库中移除并加入当前根目录排除项”。
   - 为 `missing` 项增加“从库中删除”。
   - 提供可编辑、可撤销的根目录排除项界面。
   - 防止误操作后游戏永久无法重新扫描出现。

2. **扫描过程可见性**
   - 显示扫描阶段、当前目录或最近处理项、发现数量和耗时。
   - 递归总量未知时使用不确定进度，不伪造百分比。
   - 明确显示取消、失败、不可访问和完成摘要。

3. **静态存档性能**
   - 优化首次点击“查找存档”时的大型 Ludusavi YAML 解析和匹配。
   - 保持详情打开、存档区域展开和状态查询的快速路径。

4. **便携发布**
   - 完成 PyInstaller onedir、固定版 WebView2、冻结冒烟测试和干净虚拟机验收。
   - 补充开源许可证选择、发布说明和可验证哈希。

5. **首版回归与人工验收**
   - 使用合成测试及用户本机只读样本核验扫描和引擎误判。
   - 验证中文/日文路径、断网、离线盘、目录迁移和损坏规则降级。

## 6. V0.1 明确不包含

- 常驻后台文件监控。
- 启动任意游戏时自动抓取全电脑文件变化。
- 引导式动态存档发现。
- 删除游戏后的孤立存档反推。
- 存档备份、恢复、同步和云服务。
- 对接 Steam、Epic、GOG 或其他平台账号。
- 自动联网下载封面或游戏元数据。
- 游戏翻译、注入、Hook 或修改游戏文件。
- 安装器、自动更新器和公开 Release 自动发布。

## 7. V0.2：引导式寻找存档

在 V0.1 发布并稳定后实施：

- 用户为单个游戏主动开始检测会话。
- GameShelf 建立受限目录和定向注册表基线并启动游戏。
- 用户在游戏中保存后点击“我刚刚保存了”。
- 程序聚合时间窗口内变化、过滤缓存和日志噪声。
- 用户审核并接受候选位置。

正式开始前需重新评审模块 06 的依赖、性能和隐私边界。

## 8. V0.3：孤立存档发现

- 扫描已知 AppData、LocalLow、Documents、Saved Games 和 Ludusavi 位置。
- 支持用户选择额外目录进行受限扩展扫描。
- 尝试给出游戏名或引擎建议，但不保证准确反推。
- 用户可关联现有游戏、创建仅存档卡片或忽略。
- 不读取或修改存档内容。

V0.2 和 V0.3 是独立子项目；不因为共享部分数据表就合并实施。

## 9. V0.4 及以后

候选方向：

- 存档备份与恢复。
- 版本历史与完整性校验。
- 可选的外部目录同步。
- 游戏库导入/导出。
- 更完善的自定义引擎与存档规则编辑器。
- 在线封面或元数据提供者，但必须显式启用并有缓存/隐私设计。

这些功能在前一版本稳定前不提前实施。

## 10. 质量门禁

每个代码增量按风险运行相关测试；首版候选发布必须运行：

```powershell
python -m pytest
python -m ruff check src tests
python -m mypy src
npm --prefix frontend run test:unit -- --run
npm --prefix frontend run type-check
npm --prefix frontend run build
python -m gameshelf --smoke-test
```

正式冻结产物还必须运行模块 07 定义的冻结冒烟和干净虚拟机检查。

## 11. 下一项建议任务

文档归并完成后，优先实现“游戏记录移除/忽略 + 根目录排除项编辑”。它直接解决误识别工具目录、删除根目录后大量游戏失效以及误操作难以恢复的问题，并与现有扫描模型边界清晰。

随后实现扫描详情显示，再处理首次 Ludusavi 查找性能，最后进入便携打包。
