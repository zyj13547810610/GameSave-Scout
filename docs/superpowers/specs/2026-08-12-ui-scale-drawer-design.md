# GameShelf 界面缩放与详情侧栏交互设计

日期：2026-08-12  
状态：待用户复核

## 1. 背景

当前游戏详情以固定侧栏覆盖在主界面右侧。详情侧栏和页面本身都可以滚动，因此会在窗口右边同时出现两条滚动条；鼠标位于游戏列表区域时，滚轮还会继续滚动主页面。详情只能通过右上角按钮关闭，界面文字和控件大小也不能调整。

本次改动解决以下问题：

- 提供整体界面缩放设置；
- 详情打开后，只允许详情侧栏滚动；
- 点击详情以外的左侧区域可关闭详情；
- 消除主页面与详情滚动条并排出现的视觉问题。

## 2. 已确认的交互方案

### 2.1 界面缩放

- 在顶部操作区增加“界面缩放”选择框。
- 提供 `90%`、`100%`、`110%`、`120%`、`130%` 五档，默认值为 `100%`。
- 缩放作用于整个 Web 界面，包括文字、按钮、表单、间距、游戏卡片和详情侧栏，不改变原生 Windows 窗口尺寸。
- Windows 窗口继续支持用户拖动边缘改变大小，并保留现有最小窗口尺寸限制。
- 用户选择后立即生效，不需要重启应用。
- 缩放值保存在 WebView 本地存储中。项目已将 WebView 存储位置指定为程序旁的 `data/webview`，因此迁移完整便携目录时该设置会一并迁移。
- 如果存储值缺失、损坏或不在允许范围内，自动恢复到 `100%`。

### 2.2 详情侧栏

- 详情仍从窗口右侧弹出并覆盖主界面，不重新排列游戏卡片。
- 不采用卡片重排的原因是：背景在详情打开时不可操作，重排没有明显操作收益；保持卡片位置还能避免打开和关闭详情时产生视觉跳动。
- 详情打开时，在主界面上方放置一层轻微半透明的交互遮罩，表示背景当前不可操作。
- 点击遮罩任意位置关闭详情；右上角关闭按钮和 `Esc` 键继续有效。
- 详情关闭后，将键盘焦点恢复到打开它的游戏卡片。
- 详情侧栏使用边框和阴影与背景分隔。
- 窗口较窄时，侧栏宽度自动受视口限制，不能超出窗口。

### 2.3 滚动行为

- 详情打开时锁定主页面滚动，并保持主页面原有滚动位置。
- 鼠标位于左侧遮罩区域时，滚轮不滚动主页面。
- 详情侧栏拥有独立的纵向滚动容器和唯一可见的页面级滚动条。
- 详情滚动到顶部或底部后，不把剩余滚动继续传递给主页面。
- 关闭详情后恢复主页面滚动，且不改变关闭前的页面位置。
- 隐藏主页面滚动条时应避免内容产生明显的横向位移。

## 3. 组件边界

### `UiScaleControl`

负责展示缩放选项、校验用户选择并更新当前缩放值，不关心游戏库数据。

### `useUiScale`

负责读取和写入持久化值，并把缩放值应用到界面根节点。存储异常不得阻止应用启动。

### `GameGrid`

继续持有当前选中游戏，并负责记录打开详情的卡片元素，以便关闭后恢复焦点。

### `GameDetailDrawer`

详情组件包含全窗口详情层、左侧遮罩和右侧独立滚动侧栏。它负责发出关闭事件，并在存在期间启用主页面滚动锁；卸载时必须恢复页面状态。

## 4. 数据流

1. 应用启动时读取缩放设置，校验后应用到界面。
2. 用户修改缩放档位时立即更新界面并写入本地存储。
3. 用户点击游戏卡片后，`GameGrid` 记录触发元素并打开详情层。
4. 详情层锁定主页面，遮罩接管左侧点击和滚轮，侧栏处理自己的滚动。
5. 用户点击遮罩、关闭按钮或按 `Esc` 后，详情层卸载，主页面恢复滚动，焦点返回原卡片。

## 5. 性能考虑

- 本方案不重排游戏卡片，打开详情只增加一个覆盖层和一个侧栏。
- 游戏卡片不会因为详情打开而销毁或重新创建，封面不会重新请求。
- 当前卡片封面已经使用浏览器原生 `loading="lazy"`，屏幕外封面会延迟加载。
- 本次不引入分页或虚拟列表。将来如果游戏数量达到上千并出现可测量的卡顿，再单独设计大规模列表优化。

## 6. 可访问性与异常处理

- 详情层使用对话框语义，并标记背景为不可交互。
- 打开详情后把焦点移入详情，关闭后恢复到原卡片。
- 所有关闭方式最终调用同一个关闭流程，避免滚动锁或焦点状态残留。
- 组件异常卸载时也必须清理滚动锁。
- 缩放选择框具有可读标签，可使用键盘操作。
- 尊重现有的“减少动态效果”系统设置。

## 7. 测试与验收标准

自动化测试至少覆盖：

- 初次启动使用 `100%`；
- 选择新缩放档位后立即生效并写入存储；
- 重新挂载时恢复已保存的缩放值；
- 非法缩放值回退到 `100%`；
- 点击游戏卡片打开详情；
- 点击左侧遮罩、右上角按钮和按 `Esc` 都能关闭详情；
- 详情打开时主页面具有滚动锁，关闭或卸载后滚动锁被清理；
- 详情侧栏具有独立滚动和滚动边界隔离；
- 关闭详情后焦点返回原游戏卡片；
- 不同窗口宽度和全部五档缩放下，详情不超出视口，控件不被遮挡。

人工验收时重点复核用户截图中的区域：鼠标位于左侧游戏列表时滚轮不能带动主页面；窗口右侧不能再出现两条并排的纵向滚动条。

## 8. 本次不包含

- 自动改变 Windows 原生窗口尺寸；
- 详情打开时重新排列游戏卡片；
- 固定详情栏或连续浏览模式；
- 分页、虚拟列表等超大游戏库优化；
- 改变游戏扫描、封面处理和存档识别逻辑。
